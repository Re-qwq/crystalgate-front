使用教程
快速了解 CrystalGate 的各项功能
快速入门
什么是 CrystalGate

CrystalGate 是一个在线脚本运行与机器人管理平台。支持上传多种语言的脚本并实时查看运行输出，同时提供面板与机器人管理能力，方便你在手机上完成日常运维与自动化任务。

如何注册和登录

打开应用后进入登录页，点击「注册」填写用户名与密码即可完成注册；已有账号直接输入用户名、密码登录即可进入控制台。

如何创建面板

登录后进入「面板」页面，点击「创建面板」按钮，填写面板名称等信息提交后即可创建属于自己的面板。

面板管理
如何创建机器人

进入面板详情页，点击「创建机器人」，选择账号来源并填写相关信息，提交后即可在面板下创建机器人。

PE / PC 平台选择的区别

PE 为口袋版（移动端）平台，PC 为电脑端平台。请根据你实际使用的游戏客户端选择对应平台，平台不匹配可能导致启动失败。

如何启动机器人

在面板详情页点击「启动」按钮即可启动机器人，启动后可在控制台查看实时日志输出，了解运行状态。

常见错误码说明

code=32：通常表示登录态失效或需要重新验证。请到「账号管理」中重新添加或刷新该账号后再尝试启动。

运行器使用
运行器是什么

运行器是一个在线脚本执行环境，可上传脚本文件并执行命令，通过 WebSocket 实时返回 stdout / stderr 输出，方便在手机上直接运行和调试脚本。

支持的文件类型
.py Python .go Go .java Java .js Node.js .sh Shell .exe 可执行文件 .ts TypeScript .rb Ruby .pl Perl .php PHP .rs Rust .c / .cpp C/C++
如何上传文件

在「文件管理」区域点击「上传文件」按钮，选择本地脚本即可上传。上传成功后会弹出提示显示文件名，文件会出现在列表中。

如何运行文件

点击文件名可自动根据扩展名填充命令到输入框；也可点击文件操作中的「运行」按钮直接执行；或在命令框中手动输入命令后点击「执行」。

如何使用 WebSocket 实时输出

执行命令后系统会自动通过 WebSocket 推送 stdout / stderr，实时显示在输出区。若 WebSocket 不可用，会自动回退到 HTTP 模式获取完整输出。

文件管理操作

每个文件支持以下操作：运行、下载、重命名、压缩、删除。点击文件条目上对应的按钮即可执行相应操作。

账号管理
如何添加 4399 账号

在账号管理中点击「添加账号」，填写 4399 账号信息并完成验证后即可添加。添加成功的账号可用于创建和启动机器人。

sauth_json 自动刷新机制

系统会自动维护 sauth_json 登录凭证，在临近过期时自动刷新，无需手动干预。若自动刷新失败，系统会提示你重新登录该账号以恢复凭证有效性。
