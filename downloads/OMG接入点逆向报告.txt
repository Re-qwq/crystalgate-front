## 一、什么是 OMG 接入点

**NeOmega (欧米伽, Ω)** = 网易租赁服机器人最强接入方案, 三层结构:

1. **omega_launcher / neomega_access_point** (Go 二进制, 闭源): 进服 + 协议层, 向本地开放 **TCP 端口** (默认 24013)
2. **neomega_linux_amd64.so** (C 动态库): 由官方 `neomega/c_api/main.go` (1181行, 开源!) 编译, 暴露 100+ C ABI 函数
3. **Python 封装** (ToolDelta neo_conn.py 1345 行 + 官方 conn.py 1299 行): ctypes 加载 .so 调用

**核心原理**: Python ctypes 加载 .so → C ABI 与接入点进程通信 (TCP localhost) → 接入点持有游戏连接。

**官方设计理念** (来自 readme.md): 核心部分 (机器人本体) 精简稳定, 业务部分 (插件) 通过数据接口远程附加, 避免业务错误拖垮核心。

## 三、启动流程 (逐步还原)

### 模式 A: NeOmegaAccessPoint (独立接入点)
```python
# 1. load_lib(): ctypes 加载 neomega_linux_amd64.so (Linux) / .dll (Windows) / .so (Android Termux)
#    APIVersion = LIB.OmegaAPIVersion()  (>=100 支持 msgpack, >=115 支持 SetPacketFilterMode)

# 2. 启动接入点 (参数完全还原):
neomega_access_point -server <租赁服号> -T <fbToken> \
    -access-point-addr tcp://localhost:<空闲端口24013起> \
    -server-password <密码> -auth-server <认证服务器URL>

# 3. 等待就绪: stdout 输出 "机器人已获得操作员权限" / "[neOmega 接入点]: 就绪"

# 4. ThreadOmega(Remote, "tcp://127.0.0.1:端口").connect():
#    ConnectOmega(address) → ListenAllPackets() → GetPacketNameIDMapping()
#    → ListenPlayerChange() → GetClientMaintainedBotBasicInfo()

# 5. 事件循环 _react(): EventPoll() 按 11 种事件类型分发
```

### 模式 B: NeOmegaLauncher (完整启动器)
```python
# 多一个参数: -storage-root <NeOmega数据目录>
# stdout 交互: "要使用和上次完全相同的配置启动吗?" → 自动回车(y)
# 就绪信号: "[neOmega 接入点]: 就绪"
```

### 模式 C: Remote (远程连接)
```python
# 配置远程地址 tcp://127.0.0.1:24020, 不启动进程, 直接 ConnectOmega
```

## 四、C ABI 函数清单 (官方 c_api/main.go 100% 还原)

### 4.1 核心连接
```c
bool OmegaAvailable()
int32 OmegaAPIVersion()
char* ConnectOmega(char* address)           // 失败返回错误串
char* StartOmega(char* address, char* jsonOptions)  // Local 模式

```

### 4.2 事件系统 (11 种事件)
```c
GEvent EventPoll()  // {EventType, RetrieverID} — 阻塞等待
// EventType ∈ OmegaConnErr/CommandResponseCB/NewPacket(MCPacket)/PlayerInterceptedInput/
//             PlayerChange/Chat/NamedCommandBlockMsg/SoftCallResp/SoftListen/SoftAPICall
char* ConsumeOmegaConnError()
char* ConsumeCommandResponseCB()            // JSON CommandOutput
MCPacketEvent ConsumeMCPacket()             // {packetDataAsJsonStr, convertError}
MCMsgpackPacketEvent ConsumeMCPacketToMsgpack()  // APIVersion>=100
ConsumeMCBytesPacket_return ConsumeMCBytesPacket()
char* ConsumePlayerChange()
void OmitEvent()                            // 丢弃当前事件 (必须, 否则 Go GC 无法回收)
```

### 4.3 命令 (4 身份 × 2 模式)
```c
void SendWOCommand(char* cmd)                       // 设置命令 (最高权限)

void SendPlayerCommandNeedResponse(char* cmd, char* retrieverID)

// 回包: retrieverID ("cmd_callback_N" 计数器) → CommandResponseCB 事件匹配
```

### 4.4 数据包 (4 编码)

char* SendJsonGamePacket(int32 id, void* bytes, int len)

### 4.5 玩家 PlayerKit (50+ 函数, 全部 Get+Set)

### 4.7 Soft API (插件间 RPC, OMG 独有)
```c
void SoftCall(char* api, int is_bytes, void* payload, int len, char* retrieverID)
void SoftListen(char* api, int listen_bytes)
void SoftPub(char* api, int is_bytes, void* payload, int len)
void SoftReg(char* api, int is_bytes_api)          // 注册远程 API
void FinishSoftCall(char* resp_id, int is_bytes, void* payload, int len, char* err)
```
**机制**: 插件 `soft_reg("插件.api", handler)` 注册 → 其他插件 `soft_call` 跨进程调用 → retrieverID 异步回包。NeOmega 生态插件互通标准。

## 五、官方核心库结构 (neomega-core, 559 Go 文件)

```
neomega-core/
├── neomega/               ← 框架核心 API
│   ├── omega.go           ← MicroOmega 接口 (GameCtrl/PlayerKit/CmdSender/InfoSender...)
│   ├── fbauth/            ← ★FastBuilder 认证 (client.go 208行 + nemc_access_wrapper.go 63行)
│   ├── c_api/             ← ★C 动态库官方源码 (main.go 1181行 + conn.py 1299行 + access.py 34行)
│   ├── blocks/            ← 方块转换 (gen_map_neo 33MB 数据 + bedrock_java/schem 映射)
│   ├── chunks/            ← 区块定义与转换
│   ├── rental_server_impact/  ← 租赁服影响 (access_helper + info_collect_utils)
│   ├── supported_nbt_data/    ← NBT 数据定义 (命令方块/容器等)
│   ├── modules/ entries/ alter/ encoding/ bundle/ uqholder/   ← 各功能模块
├── minecraft/             ← 网易协议 (gophertunnel fork, 835 文件含 40+ block_actors)
│   ├── protocol/packet/   ← 全部数据包定义
│   └── protocol/block_actors/  ← ★command_block.go/chest.go 等 40+ 方块实体
├── minecraft_neo/         ← 网易特有: cascade_conn (级联连接) + login_and_spawn_core (登录生成核心) + game_data
├── nodes/                 ← 节点/连接抽象 (underlay_conn 底层连接)
└── i18n/ utils/           ← 国际化 + 工具
```

**fbauth (FastBuilder 认证) 关键** — OMG 进服认证全开源:
```go
// nemc_access_wrapper.go — 网易认证链构建包装
// client.go — FastBuilder API 客户端 (auth-server 交互, token 获取, 服务器信息查询)
```

- **命令回包** retrieverID 模式 = CrystalGate CMD_WAIT 原型

- **LoadBlobCache** 区块级缓存, 可优化建筑导入
- **Soft API** 未来插件系统可借鉴的跨进程 RPC
