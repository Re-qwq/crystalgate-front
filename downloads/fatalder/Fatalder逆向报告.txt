- 这是 **fatalder-remote**（云 worker 远程客户端），Android ARM64 版本

## 三、Worker 协议完整还原（40+ 消息类型）

### 3.1 任务/作业协议
```
JobSpec          — 作业规格 (含 RuntimeConfig)
TaskSpec         — 任务规格
  ├── BuildTaskSpec    — 构建任务 (build_mode/auto_enter_fix/command-block-speed/...)
  ├── CommandTaskSpec  — 命令任务
  └── ExportTaskSpec   — 导出任务
BuildRuntimeConfig — 构建运行时配置
PrepareJobRequest / PrepareProgress / PrepareProgressResponse — 准备阶段
StartJobRequest / StartReceipt — 启动任务
RecoverJobRequest / DiscardRecoveryResult — 恢复任务
SkipTaskRequest — 跳过任务
```

### 3.2 转换/构建流协议
```
ConversionRequest / ConversionResponse / ConversionProgress
ConversionStreamFrame / ConversionStreamError
BuildConversionFinishedPayload
TargetSpec / TargetSummary / ListTargetsResponse
ObjectRef / OversizeUploadMessage
UploadPolicyResponse — 上传策略 (对象存储)
TaskLocalGateChallenge / TaskLocalGateAckRequest — ★本地门挑战/确认
```

### 3.3 校验函数（协议字段规则全暴露）
```
validateObjectName      — 对象名校验
validateRentalServerCode — 租赁服号校验
validateRuntimePasscode  — 运行时密码校验
validateOpaqueID         — 不透明 ID
validateIdempotencyKey   — 幂等键
validateDisplayText      — 显示文本
validateBuildTaskValues  — 构建任务字段
```

## 五、网络协议

```
服务器: https://fatalder.flyshop.chat
API 头: X-Fatalder-API-Key (API 密钥认证)
端点:   /v2/jobs/%d (任务状态查询)
对象存储: /v2/objects/policy (上传策略, 类似 S3 presigned URL)
下载:   --object-id + --sha256 + --size (对象完整校验)

认证链:
  API Key (X-Fatalder-API-Key)
  Personal Cookie (个人账号 Cookie 持久化, 加密存储)
  Worker Token (worker token 文件, bearer token)
  Server Passcode (租赁服密码, 本地加密存储 .fatalder-server-passcodes)
```

## 八、与 FA (FateArk) 的关系

**Fatalder 是新一代 FA 接入点**：
- 旧 FateArk: 本地 gRPC 架构（ToolDelta 直接连）
- 新 Fatalder: **云端 worker 架构**（客户端进服 + 服务器调度 + 对象存储）
- 作者: maoqijie（旧版可能是同一团队）
- 版本迭代: v26.8.16 = 2026-08-16 最新版

**对 CrystalGate 的价值**：
1. Fatalder 云服务 (`fatalder.flyshop.chat`) = 现成的云 bot 方案替代 Prism！
2. worker 协议 = 可直接对接的 HTTP API（比逆向 gRPC 简单）
3. 构建/导出任务化 = CrystalGate 建筑功能可照搬架构
